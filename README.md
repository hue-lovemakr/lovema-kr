# Seoul Theme for VS Code

**Seoul Theme** is a color suite for VS Code-compatible editors, inspired by traditional Korean colors—including *O-bang-saek*—and the official Seoul color palette. Three distinct themes bring the atmosphere of Seoul and Korean visual culture to the editor while maintaining a comfortable, readable visual hierarchy.

## 🎨 Themes

### 1. Seoul Dancheong (단청)

> *The Vivid Palace.*

![Seoul Dancheong](https://lovema.kr/seoul/preview/dancheong.png)

- **Mood**: Majestic, vivid, artistic, and structural.
- **Concept**: Inspired by *dancheong*, the vibrant decorative coloring found on traditional Korean wooden architecture.
- **Design**:
  - A deep green-grey editor, reminiscent of *giwa* roof tiles, surrounded by brighter `Giwajinhoesaek`-derived UI surfaces.
  - `Damjusaek` for keywords, `Seoul Sky Blue` for functions and properties, `Jahwangsaek` for strings, and jade-green tones for types.
  - Clear panel and editor-group boundaries create a structured two-tone workspace while keeping the editor itself comfortably dark.
- **Recommended for**: General and daylight coding, presentations, and visually separating editor groups and panels.

### 2. Seoul Morning (서울의 아침)

> *The Paper Light.*

![Seoul Morning](https://lovema.kr/seoul/preview/seoul-morning.png)

- **Mood**: Fresh, clean, and soft.
- **Concept**: Sunlight filtering through *hanji*, traditional Korean paper.
- **Design**:
  - A soft, near-white paper background instead of a stark blue-white surface.
  - Green-grey `Giwajinhoesaek`-derived ink tones instead of pure black for primary text.
  - Muted `Yubaesaek` rice-color surfaces with red, blue, and green accents derived from the base palette.
- **Recommended for**: Bright environments, morning work, and reading documentation.

### 3. Seoul Night (서울의 밤)

> *The Classic Dark.*

![Seoul Night](https://lovema.kr/seoul/preview/seoul-night.png)

- **Mood**: Calm, quiet, and deep.
- **Concept**: A quiet walk along the Han River at night.
- **Design**:
  - A low-luminance `Heukbaek` background with warm, earthy foreground colors.
  - `Sosaek` warm beige and `Jangdansaek` soft red, complemented by muted blue, jade, and amber accents.
  - Large UI surfaces share one quiet base so that syntax remains the primary focus.
- **Recommended for**: Night coding, long sessions, and low-light environments.

## 🌿 Philosophy: Visual Comfort

Seoul Theme is not a port of another theme. It uses traditional Korean colors drawn from nature to bring a calm, harmonious character to the editor.

- **Comfort before spectacle**: Large dark surfaces avoid pure black, while the light theme uses softened, paper-like neutrals. Pure white is reserved for small, high-priority UI text where needed.
- **Natural harmony**: Traditional Korean colors inspired by soil, stone, pine trees, flowers, and natural pigments give the themes a cohesive character.
- **Readable hierarchy**: Primary text receives strong contrast, while comments, inactive tabs, guides, and borders remain intentionally quieter.
- **Controlled accents**: Saturated colors are reserved for syntax roles, focus, status, and small interactive elements rather than large backgrounds.
- **Host-aware theming**: VS Code-compatible editors and third-party webviews can map theme variables differently. A webview may also draw its own internal background beyond what a color theme can directly control.

The themes aim to reduce unnecessary glare, contrast fatigue, and visual noise. However, no color theme can guarantee the prevention of eye strain; ambient light, display brightness, font size, viewing distance, and regular breaks remain important.

## 🛠 Installation

1. Open the **Extensions** sidebar in VS Code or a compatible editor.
2. Search for **Seoul Theme** by `lovema-kr`.
3. Install the extension.
4. Open **Preferences: Color Theme** and select **Seoul Night**, **Seoul Dancheong**, or **Seoul Morning**.
